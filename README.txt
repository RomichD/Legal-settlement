ЮРИДИЧЕСКИЙ КАЛЬКУЛЯТОР — СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS

1. На github.com создайте НОВЫЙ ПУСТОЙ репозиторий (без README и .gitignore).
2. Распакуйте архив и загрузите ВСЁ содержимое папки LegalCalculatorAndroid в корень репозитория.
   Обязательно загрузите скрытую папку .github и папку gradle.
3. После Commit changes откройте вкладку Actions. Запустится Build APK.
4. Дождитесь зелёной галочки (обычно 3–5 минут), откройте этот запуск.
5. Внизу в Artifacts скачайте legal-calculator-apk, распакуйте его.
6. Внутри будет app-debug.apk. Передайте его на телефон и установите.

В приложение уже встроен присланный актуальный index.html.
