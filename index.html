Проценты по договору займа

Калькулятор рассчитывает проценты за фактическое пользование суммой займа, учитывает частичные платежи и показывает их распределение. Для точного расчёта выберите правила, которые прямо предусмотрены договором: ставку, базу дней, даты и очередность погашения.

Указывайте издержки, только если они относятся к получению исполнения по обязательству. Неустойка и проценты за просрочку рассчитываются отдельно в соответствующих вкладках.

Платёж начисляется на задолженность в указанную дату. Для досрочного возврата укажите фактическую дату поступления денег.

Расчёт договорной неустойки

Неустойка начисляется на непогашенную сумму просроченного обязательства со дня, следующего за установленной датой платежа, по день фактической оплаты не включительно. Если договор содержит иной порядок, выберите соответствующую настройку либо скорректируйте даты расчёта.

Выберите правило, которое установлено договором или следует из принятой в деле методики расчёта. По умолчанию дата расчёта включается.

Добавьте каждую сумму отдельно: укажите дату, когда платёж должен был быть внесён, а также просроченные основной долг и проценты. Неустойка начнёт начисляться по каждой строке только после наступления её собственной даты просрочки.

Калькулятор задолженности по кредитной карте

Расчёт ведётся по фактическим датам операций и платежей. Проценты начисляются ежедневно на остаток основного долга. Льготный период применяется только в пределах настроенных условий.

Для режима «полностью погасить» льгота по операции сохраняется, если к дате окончания льготного периода эта операция полностью погашена. При непогашении проценты начисляются с даты операции.

Минимальный платёж показывается как справочная величина. Просрочка определяется, если до даты очередного платежа внесено меньше рассчитанного минимального платежа.

Укажите покупки, выдачу наличных, комиссии и иные операции, увеличивающие задолженность. Комиссия может быть отдельной операцией либо частью суммы операции.

Срок исковой давности

Калькулятор рассчитывает срок исковой давности отдельно по каждому обязательному платежу. Дата начала — день, следующий за датой, когда платёж должен был быть внесён. Результат носит справочный характер: признание долга, требования о досрочном возврате и судебные акты должны подтверждаться документами.

Срок сравнивается именно с датой подачи иска в суд, а не с датой принятия иска, вынесения решения или выдачи исполнительного листа.

Срок исковой давности по этой сумме считается отдельно: с даты, следующей за днём истечения срока для исполнения требования. Расчёт по отдельным платежам ниже сохраняется как самостоятельный результат.

Период со дня обращения за судебным приказом до дня отмены учитывается как период приостановления течения срока. Если после отмены оставалось менее шести месяцев, срок продлевается до шести месяцев.

Указывайте эти даты, только если претензионный порядок был обязательным по закону или договору.

Указывайте дату только при наличии юридически значимого действия: письменного признания, заявления о реструктуризации, соглашения, частичной оплаты именно конкретного долга и т. п.

Вносите не даты фактических оплат, а даты, когда платежи должны были быть внесены по договору или графику. Для кредита указывайте каждый ежемесячный обязательный платёж отдельно.
