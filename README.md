Программа для различных юридических расчётов. Использовать только на свой страх и риск.

## Автоматическое обновление данных

### Ключевая ставка ЦБ и ИПЦ
Загружаются онлайн при открытии страницы через прокси
(`?route=key-rate`, `?route=cpi`). Если сеть недоступна — используются
встроенные таблицы.

### Предельные значения ПСК для микрозаймов
Обновляются автоматически при публикации новых данных Банка России:

- **GitHub Action** `.github/workflows/update-psk.yml` — раз в неделю
  скачивает самый свежий файл `*_mfo.xlsx` со страницы
  [статистики ПСК ЦБ РФ](https://www.cbr.ru/statistics/bank_sector/psk/),
  извлекает предельные значения (графа «Предельные значения ПСК») и
  обновляет их в `index.html` (массивы `MFO_PSK_UNSECURED` /
  `MFO_PSK_SECURED`, переменную `MFO_PSK_QUARTER` и справочную таблицу
  во вкладке «Микрозаймы»), после чего делает коммит. Если новых данных
  нет — коммит не создаётся.
- **Онлайн-режим** (опционально): если на прокси-сервере данных добавлен
  маршрут `?route=psk` (код — `psk_route.js`, зависимость `xlsx`),
  калькулятор подтягивает ПСК при каждом открытии, как ставку и ИПЦ.

Скрипт обновления: `.github/scripts/update_psk.py`
(запуск вручную: `python3 .github/scripts/update_psk.py index.html`).
